# 🔮 Jujutsu AI: Hybrid Domain Expansion Assistant

Este es un asistente conversacional híbrido y de bajo consumo desarrollado en Python. Permite interactuar de forma interactiva con el lore profunda, mecánicas de energía maldita y expansiones de dominio de **Jujutsu Kaisen**.

## 🚀 Características
- **Interfaz de Chat Interactiva:** Diseño responsivo con burbujas de diálogo estilizadas.
- **Voto Vinculante (Binding Vow):** Función en tiempo real para modificar la extensión de las respuestas de la IA.
- **Base de Conocimiento de Grado Especial:** Enciclopedia técnica indexada localmente (`conocimiento/Jujutsu_encyclopedia.md`).

## 🛠️ Stack Tecnológico
- **Backend:** Python con FastAPI (Inferencia Local Asíncrona).
- **Frontend:** Vanilla JS / HTML5 / CSS3.
- **Modelos Compatibles:** Phi-3-mini-4k / Gemma-2-2B (Formato GGUF a través de Edge AI).

## 📦 Ejecución Local
Para arrancar el servidor web local, simplemente ejecuta el archivo automatizado:
```bash
iniciar.bat
```
